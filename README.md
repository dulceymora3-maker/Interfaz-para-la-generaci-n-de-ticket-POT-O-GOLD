Interfaz para la generación de tickets POT O’ GOLD

Descripción

Aplicación de escritorio desarrollada para la generación de tickets POT O’ GOLD mediante una interfaz gráfica que permite visualizar y procesar información en formatos hexadecimal (HEX) y ASCII (ASC).

Entorno de desarrollo

* Software: Visual Studio Code
* Versión: 1.146.0
* Lenguaje: C#
* Framework: .NET 8.0
* Interfaz gráfica: WPF
* Sistema operativo: Windows 10 x64

Archivos principales

* MainWindow.xaml: diseño de la interfaz.
* MainWindow.xaml.cs: lógica del programa.
* App.xaml: configuración de la aplicación.
* PrometeoTicketHP.csproj: configuración del proyecto.
